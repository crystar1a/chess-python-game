# Pixel Chess UI redesign

**Goal:** Rebuild the pygame screens as a coherent chess-club interface while preserving the current game and authentication flows.

**Direction:** Charcoal surfaces, warm ivory type, olive board squares and restrained brass accents. Use the existing pixel pieces as the visual identity; create no website or new dependencies.

1. Establish reusable pygame colors, typography and controls; redesign authentication and menu screens without changing their hit areas.
2. Apply the same visual language to setup, room and game screens, including board, player bars, promotion and feedback states.
3. Run the existing tests and inspect rendered pygame screenshots; exercise authentication and navigation without a server.

The requested design-taste-frontend skill targets websites. Its HTML, browser and website gate steps do not apply to this pygame application; visual verification uses screenshots of the actual game instead.
